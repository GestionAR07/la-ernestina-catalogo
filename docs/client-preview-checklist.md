# Checklist de revisión — preview La Ernestina

Usá este listado para confirmar o corregir datos antes de la publicación definitiva.
**No completar datos inventados**: solo valores reales del comercio.

## Identidad

- [ ] Nombre comercial: ¿confirmás **La Ernestina**?
- [ ] Descripción corta: ¿confirmás **Forrajería & Alimentos**?
- [ ] Logo / tipografía / colores: ¿la identidad visual de la preview es correcta?
- [ ] Imagen principal (hero): ¿la foto actual es la definitiva?

## Contacto

- [ ] Número de WhatsApp (formato internacional, **solo dígitos**, sin `+`, espacios ni guiones). Ejemplo de formato: `54911XXXXXXXX`
- [ ] Teléfono visible al público
- [ ] Dirección del local
- [ ] Horarios de atención
- [ ] Redes sociales (Instagram, Facebook, etc.) con URLs finales

> Mientras el WhatsApp no esté confirmado, el botón de checkout permanece **bloqueado** a propósito.

## Catálogo

- [ ] Categorías correctas y completas
- [ ] Productos correctos (nombres, marcas, descripciones)
- [ ] Presentaciones correctas (kg / envases)
- [ ] Precios correctos o “Consultar precio” donde corresponda
- [ ] Productos destacados (“Los más pedidos”)
- [ ] Productos faltantes a agregar
- [ ] Imágenes de producto (hoy hay placeholder neutro)

## Pedido

- [ ] Modalidad **Retiro** ¿correcta?
- [ ] Modalidad **Consultar envío** ¿correcta?
- [ ] Texto / tono del mensaje de WhatsApp
- [ ] Medios de pago a informar (si corresponde)
- [ ] Zonas o condiciones de entrega (si corresponde)

## Responsive y usabilidad

- [ ] Se ve bien en celular
- [ ] Se ve bien en tablet / escritorio
- [ ] El pedido (drawer) es claro
- [ ] Textos y precios se leen bien

## Aprobación

- [ ] Preview aprobada para seguir a configuración comercial real
- [ ] Preview aprobada para publicación definitiva (solo después de WhatsApp y datos reales)

---

**Importante:** no enviar pedidos de prueba al WhatsApp del comercio sin autorización explícita.
